# Week 1 - Student Performance EDA

## Overview
This project analyzes student exam performance to find patterns based on gender, parental education, lunch type, and test preparation.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter/Google Colab

## Key Findings
- Test prep improves scores.
- Females excel in reading/writing; males in math.
- Standard lunch correlates with better performance.
